# PredictIQ — Documentation Guide

## Source-of-truth order
1. Project Charter — what PredictIQ is
2. Architecture — how it connects
3. Features — what it provides
4. Roadmap — implementation order
5. API Contract — integration boundary
6. AI/ML Strategy — intelligence maturity
7. Decisions — why major choices were made

If implementation conflicts with a locked document, either change the implementation or explicitly update the document and record the decision.

## Principle
Documentation exists to help the team build, integrate, test, and explain PredictIQ—not merely to increase file count.
